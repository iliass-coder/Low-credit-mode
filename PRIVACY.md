# Privacy

Low Credit Mode is a skill package. This project operates no hosted service and does not ask for account credentials, API keys, or payment details.

The optional `budget.py` helper reads JSON from standard input and writes a calculation to standard output. It makes no network requests, does not write files, and includes no analytics or telemetry. It returns selected quota-window data, not unrelated fields from the input.

Your AI host can process prompts, files, tool outputs, and usage readings according to its own terms, retention settings, and permissions. Installing this skill does not change those policies or grant additional access. Consult your host's documentation for its data handling.

Keep real account identifiers, balances, quota snapshots, and transcripts out of commits and public issues. Use synthetic examples when reporting problems. Development tests use synthetic readings and isolated temporary workspaces.
