# Changelog

## 0.2.0 — 2026-11-11

Public beta preparation:

- Added MIT licensing, public installation and compatibility guidance, privacy and security policies, and contribution guidance.
- Replaced placeholder author information with the public maintainer identity.
- Added an optional dependency-free helper for quota validation, budget planning, and checkpoint decisions.
- Defined handling for ambiguous or invalid readings, invalid fractions, zero budgets, disappearing windows, and possible resets.
- Added regression tests and reproducible release packaging.
- Replaced internal development reports with maintained testing guidance. Raw trial outputs stay local and ignored.

Budget enforcement, live host integration, and measured credit savings remain outside the verified guarantees of this beta.
